# Along Copilot Kit

Drop these files into the root of your project repo:

    AGENTS.md                      rules Copilot follows on every request
    .github/copilot-instructions.md  same rules (Copilot reads this path)
    docs/SPEC.md                   detailed requirements, read on demand
    docs/prompts/stage-*.md        paste one at a time into Copilot Agent mode

How to use:
1. Copy everything into your repo root and commit.
2. Open Copilot Agent mode, paste the contents of stage-1, wait for "Done when" to pass.
3. Start a NEW chat for each next stage. Do not paste stages together.
4. If it stalls: "continue from where you stopped; run the tests first."

Before launch: get a Bangladesh lawyer's view on the service model and payment flow.
